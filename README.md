# desk companion

The phone side of [desk](https://github.com/msieur-gab/desk): an installed page that takes a
link shared from any app and, later, keeps the desk's articles on the phone for reading offline.
It lives here, on a public HTTPS address, because a phone only lets a page into its share sheet,
and lets it start offline, when it is installed from one. The desk itself is plain HTTP on the
local network. No article and no secret is in this repository: what is kept stays on the phone
and on the desk.

For now it is a test bench (`index.html`): it finds out how this phone lets the page talk to a
desk on the local network, before the real thing is built.
